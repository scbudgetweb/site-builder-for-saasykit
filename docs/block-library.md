# Block library

**Where:** Admin › Website › Block library
**Who can use it:** anyone who can work on pages (the page permissions)

Save a block, or a whole section, once and reuse it on as many pages as you like. A reused block is **linked**: change it in the library and every page using it updates straight away. It suits things that should look the same everywhere, such as a call to action, a partner logo strip or opening times.

## Saving a block to the library

In the [page editor](pages.md), each block's card has a **Save to library** button (the bookmark icon). It works on blocks inside a section's rows too, and on a whole section.

1. Click **Save to library**.
2. Give it a **name**, for example *Book a room* or *Partner logos*.
3. Leave **Link this block to the library** on to swap the block on this page for a linked one, so it updates with the library. Turn it off to put a copy in the library and leave this block as it is.
4. **Save** the page.

You can also make a library block from scratch: **New library block** in the Block library.

## Using a library block on a page

1. **Add block** and choose **Saved block (library)**.
2. Pick the library block from the list, which shows each one's name and the kind of block it is.
3. Save the page.

The card shows the library block's name and a **Linked** tag. Inside a section's row you can only choose library blocks that can go in a row: not a Hero, Banner or Section.

A linked block uses the library block's settings, including its style and layout. To change it on one page only, click **Make an editable copy** on its card. The link is replaced by a normal copy you can edit, which no longer updates from the library.

## Editing a library block

Open it in the Block library, change it in the same editor as on a page, and **Save**. Every page using it shows the change. **Used on** lists those pages, with a link to each. A page in the bin is marked *(in the bin)*.

The list of library blocks shows each block's name and kind, how many pages use it, and when it was last changed. Filter it by kind of block.

## Deleting a library block

A library block that pages use can't be deleted. You're told which pages use it, so you can remove it from them or make an editable copy there first. A library block nothing uses deletes straight away.

## Images

Images in a library block are kept as long as any page, library block or page revision uses them. When nothing uses an image any more, it's deleted from storage.
